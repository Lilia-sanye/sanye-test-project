# 用例表列名映射与模板剥离

读取文件时 **先识别表头**，再映射到逻辑字段（未命中则向用户确认）。

| 逻辑字段 | 常见列名（优先级从左到右） |
|----------|---------------------------|
| 用例ID | 用例ID、ID、编号 |
| 标题 | 用例标题、标题 |
| 模块 | 所属模块、用例目录、模块 |
| 等级 | 等级、优先级、用例等级 |
| 前置条件 | 前置条件、precondition |
| 操作步骤 | **步骤描述**、操作步骤、测试步骤 |
| 预期结果 | 预期结果、expected |

## 常见导出格式

**PingCode / 研发云**（如 `界面和任务设置.xlsx`）：

`用例ID、用例标题、用例目录、等级、前置条件、步骤描述、预期结果`

**七列表 CSV**（如满袋检测）：

`用例类型、所属模块、用例标题、前置条件、操作步骤、预期结果、用例等级`

## 模板包裹剥离

转化 Midscene 前须剥离（若存在），只保留业务步骤与断言语义：

| 包裹标记 | 处理 |
|----------|------|
| `【测试环境】`…`【记录要求】`…`【本用例前提】` | 删除外壳，环境写入前置条件 |
| `【执行通则】`…`【操作步骤】` | 只保留步骤正文 |
| `【结果判定】`…`【预期现象】` | 只保留预期正文 |

脚本 `screen_ui_task_cases.py` 会尝试自动剥离；源表越干净，分档与草稿越准。
