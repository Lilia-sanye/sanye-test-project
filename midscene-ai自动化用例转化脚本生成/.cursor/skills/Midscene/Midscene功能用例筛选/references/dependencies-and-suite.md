# 任务依赖与测试套件组织

用于生成 `*_依赖关系分析.md` 与套件顺序建议。**YAML 中的 `dependsOn` / `shareSteps` 为组织约定**；若 `@midscene/cli` 不支持，退化为 flow 内联或注释（见安卓技能 [yaml-schema.md](../../Midscene安卓自动化脚本/references/yaml-schema.md)）。

## 依赖识别依据

| 依据 | 说明 | 示例 |
|------|------|------|
| 前置条件字段 | 用例表前置条件 | 「先完成登录」 |
| 模块关系 | 同模块按业务流程排序 | 创建 → 查看 → 编辑 |
| 数据依赖 | 上游用例产出数据 | 创建任务供后续编辑 |
| 业务流程 | 登录 → 查询 → 操作 → 验证 | — |

## 依赖类型

| 类型 | 处理 |
|------|------|
| 前置依赖 | `dependsOn: [用例A]` 或注释标明顺序 |
| 数据准备 | 标记 `dataPreparation` 或独立准备 task |
| 清理 | 标记 `cleanup` 或套件末尾 task |
| 独立用例 | 可任意顺序执行 |

## 循环依赖

检测到 `A → B → C → A` 时须在报告中 **⚠️ 警告**，建议打破循环或合并用例。

## 套件组织

- 按 **所属模块 / 用例目录** 分组。
- 组内按 **等级 P0 → P1 → P2** 排序。
- **共享步骤**（登录、回主页）写入 `*_共享步骤.csv`，精修时提升到 `agent.aiActContext` 或 `shareSteps`（若 CLI 支持）。

## 草稿 YAML 范围

默认仅为 **P0 且 A 档**（或用户指定）在 `midscene自动化输出/drafts/` 生成草稿；终稿由 **Midscene安卓自动化脚本** 写入 `midscene自动化输出/scripts/`。

## 大表筛选后拆终稿套件

当 `界面和任务设置` 等模块 A 档 >30 条时，**依赖分析报告**应补充「建议终稿文件名」表，例如：

| 模块/入口 | 建议终稿 |
|-----------|----------|
| 主界面（无/有任务） | `主界面_有地图无任务_自动化测试.yaml`、`主界面_有地图有任务_自动化测试.yaml` |
| 快速任务（点地图） | `快速任务_自动化测试.yaml` |
| 新建 / 编辑 | `新建任务_自动化测试.yaml`、`编辑任务_自动化测试.yaml` |

细则与执行顺序见 [domain-ui-task-setting.md](../../Midscene安卓自动化脚本/references/domain-ui-task-setting.md)。**不要**将 `build_midscene_yaml.py` 单文件输出直接当作唯一终稿。
