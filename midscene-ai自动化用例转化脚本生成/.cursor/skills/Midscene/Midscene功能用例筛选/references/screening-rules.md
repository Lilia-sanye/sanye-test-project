# 筛选规则（v3）

与 `tools/screen_ui_task_cases.py` 口径一致。Agent 手工分档时须遵守本表。

## 1. 适用场景 → 通常 A 或 C（改写后 A）

| 用例类型 | 条件 | 示例 |
|----------|------|------|
| UI 操作 | 步骤含高优先级词 | 点击登录、输入用户名 |
| 界面跳转 | 进入/打开/返回/切换 | 进入系统设置 |
| 手势 | 拖动、缩放、长按、滑动 | 按住任务卡片拖动 |
| 视觉断言 | 仅「查看状态栏/图标」且目录含状态栏/主界面/地图 | 查看状态栏时间 → 标 C，改写 `aiAssert` |
| 流程验证 | 步骤可拆为 1～8 条 `ai:` + 1 条 `aiAssert` | 选择目的地并确认 |

## 2. 不适用或仅 B 档 → 不得标 A

| 类型 | 处理 | 示例 |
|------|------|------|
| 接口/性能/DB | D | 调用 API、压力测试 |
| ADB/Shell 为主 | B | `adb shell date` |
| 双板 Linux 验收 | B | SSH 执行 `timedatectl` |
| 物理射频 | B | 金属遮罩、拔卡弱网 |
| 实机作业无屏操 | D | 满袋、断点、规划日志（无点击） |

## 3. 整机 / 业务域（普渡机器人）

步骤或标题含 **满袋、倒草、断点、规划、回充、草箱、位图、割吸、机载、整机** 等，且步骤中**无**明确机载 UI 动词（点击/进入/设置等）时：

- 标 **D**，档位说明：「整机域用例，宜保留功能测试」
- **不要**强行生成 Midscene YAML

## 4. 关键词

| 级别 | 词 |
|------|-----|
| **高** | 点击、输入、选择、滑动、等待（及 tap/input/select/swipe/wait） |
| **中** | 验证、检查、显示 — 单独出现标 **C** 或 **B**，勿直接判 D |
| **扩展 UI** | 进入、打开、关闭、拖动、缩放、添加、返航、充电、设置、保存、删除、新建 |

## 5. 机载 UI 模式（界面和任务设置）

| 模式 | 分档建议 | 自动化改写提示 |
|------|----------|----------------|
| 地图点击作业区 | A（步骤含点击/选择区域） | `ai: 点击地图上「A区草坪」` + `aiAssert: 区域高亮` |
| 地图自动居中 | A 或 C | C：将「验证居中」改为 `aiAssert: 对应区域进入可见范围` |
| 列表 + / ×、拖拽排序 | A | 与 [domain-ui-task-setting.md](../../Midscene安卓自动化脚本/references/domain-ui-task-setting.md) 同源 |
| 同区添加 5 次上限 | A | `aiAssert: 第6次无法添加或提示「同一区域最多可添加 5 次」` |
| 软键盘 / 弹窗居中 | A 或 C | 设计稿常标 DESIGN；`aiAssert: 键盘弹出` / `弹窗居中` |
| Toast 短暂提示 | A | 断言完整文案，如 `任务已保存` |
| 开始作业（真实执行） | A + **副作用** | 终稿 task 注释台架；流水线可后置 |

## 6. 平台注意

- **机载屏**（整机界面、任务设置）：本技能主场景。
- **遥控 App**（PuduLink 等）：可筛 UI 用例；设备配置在安卓自动化技能中调整。
- **台架/多机/草箱物理**：标 **B** 或 **D**。
