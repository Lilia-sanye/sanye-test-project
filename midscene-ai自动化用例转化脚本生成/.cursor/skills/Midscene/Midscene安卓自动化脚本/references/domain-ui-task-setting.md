# 业务域：界面和任务设置（机载屏）

普渡机载 **作业任务 / 地图 / 快速·新建·编辑任务** 的套件拆分、入口差异与交叉引用。  
筛选源表示例：`修订版本/界面和任务设置.xlsx`。

## 何时拆套件 vs 合并

| 策略 | 适用 | 产出 |
|------|------|------|
| **按页面/入口拆套件**（推荐） | P0+A 条数多（>30）、入口不同、可独立试跑 | 多个 `midscene自动化输出/scripts/<页面>_自动化测试.yaml` |
| **单文件汇总** | 回归全量、CI 一次跑完 | `界面设置与操作_完整自动化测试.yaml` |
| **草稿** | 筛选脚本机械生成 | `midscene自动化输出/drafts/<stem>_自动化测试_草稿.yaml`（≤15 task，非终稿） |

大表筛选后：**不要**直接把草稿当终稿；按下列模块拆成终稿并精修。

## 终稿套件一览（本项目）

| 套件文件 | 入口 | 说明 |
|----------|------|------|
| `主界面_有地图无任务_自动化测试.yaml` | 首页（无任务集） | 地图、底栏、空态 |
| `主界面_有地图有任务_自动化测试.yaml` | 首页（有任务集） | 任务卡片、展开、点地图提示 |
| `快速任务_自动化测试.yaml` | **点击地图作业区** | 任务列表/可添加区域、保存为任务、开始作业 |
| `新建任务_自动化测试.yaml` | 右侧「+ 新建」 | 未添加态、定时/默认、返回未保存 |
| `编辑任务_自动化测试.yaml` | 展开任务 →「编辑任务」 | 参数页、删除整条任务集 |
| `地图界面_自动化测试.yaml` | 地图相关 | 建图/区域展示（按需求） |
| `界面设置与操作_自动化测试.yaml` | 混合 P0+A | 可由 `build_midscene_yaml.py` 生成后再拆 |

说明文档（与 YAML 成对交付）：`midscene自动化输出/report/<套件名>_自动化用例说明.md`。

## 同源交互规则（只维护一份语义）

以下规则在 **快速任务 / 新建任务 / 编辑任务** 三页一致（设计稿已注明）：

- 地图点击添加 ↔ 可添加区域「+」添加，地图高亮
- 地图再次点击 / 任务列表「×」删除，取消高亮
- 任务列表长按拖拽排序
- 同一区域最多添加 **5 次**，超出后从可添加列表隐藏
- 铅笔图标进入 **任务参数设置**

**写法约定**：在任一套件 YAML 文件头注释中写：

```yaml
# 关联：新建任务_自动化测试.yaml、编辑任务_自动化测试.yaml（添加/删除/5次/拖拽规则同源）
```

精修其中一套件时，另两套件中对应 task 的 `ai`/`aiAssert` 应保持一致（区名、按钮文案除外）。

## 推荐执行顺序（流水线）

```
主界面_有地图无任务  →  主界面_有地图有任务  →  快速任务
        ↓（可选）
新建任务  →  编辑任务（会改/删任务集数据，放流水线末尾或单独跑）
```

- **快速任务**：`保存为任务` 会写入首页列表；`开始作业` 会真实启动作业（台架）。
- **编辑任务**：删除类 task 破坏数据，勿与冒烟套件默认串联。

## 实机文案（device-lexicon）

地图名、区名、㎡ 标注因地图而异。终稿文件头须注明：

```yaml
# 区域名、地图名请与实机一致（如 A区草坪 / A区-前草坪），不一致时只改 ai 文案
```

项目词表见 [device-lexicon.md](./device-lexicon.md)（人工维护，Agent 精修前对照）。
