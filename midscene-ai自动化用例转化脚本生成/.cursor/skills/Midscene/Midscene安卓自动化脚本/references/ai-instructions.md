# `ai:` / `aiAssert:` 写法

## 推荐

```yaml
- ai: 点击主界面「设置」
- ai: 在 WiFi 列表中关闭 WiFi 开关
- ai: 等待直到状态栏显示「无网络」
- aiAssert: 状态栏 WiFi 图标消失，4G 图标仍显示
```

## 避免

```yaml
- ai: 验证网络模块正常          # 太抽象
- ai: 执行用例步骤 3            # 无界面语义
- aiAssert: Linux 从板时间与 Android 偏差小于 1 秒   # → B 档人工验收
```

## 禁止「若有…」条件分支

AI 自己判断"有没有弹窗/提示"是不可靠的，极易误判导致超时。

```yaml
# ❌ 禁止
- ai: 若有未设置返航点提示，点击关闭
- ai: 若有未设置回充点提示，点击关闭

# ✅ 正确：拆为独立 task，断言"按钮有响应"即可
- name: "返航按钮点击有响应"
  flow:
    - ai: 点击底部快捷栏「返航」按钮
    - ai: 等待1.5秒
    - aiAssert: 弹出返航确认弹窗或未设置返航点提示，或开始返航流程，按钮点击有响应
    - ai: 若弹出弹窗或对话框，点击弹窗中的关闭按钮关闭弹窗
    - ai: 等待直到回到主界面地图页
```

唯一例外：**「若弹出弹窗或对话框，点击关闭」** 可以保留，因为无论弹窗内容是什么，关闭操作（X/取消/返回）是通用操作。

## Task 自包含闭环

每个 task 开头和结尾都必须是**相同的稳定状态页面**（通常是主界面地图页）。

```yaml
- name: "设置按钮跳转设置页并返回"
  flow:
    - ai: 等待直到进入主界面地图页          # ← 入口：确认起点
    - ai: 点击底部快捷栏「设置」按钮
    - ai: 等待直到进入设置页面
    - aiAssert: 页面顶部标题显示「设置」
    - ai: 点击左上角返回按钮
    - ai: 等待直到回到主界面地图页          # ← 出口：恢复起点
    - aiAssert: 回到主界面地图页，底部快捷栏可见
```

禁止：前一个 task 停在子页面、下一个 task 假设"已在主界面"。

## 断言必须具体

```yaml
# ❌ 禁止模糊断言
- aiAssert: 页面为系统或应用设置页，非白屏、无闪退
- aiAssert: 页面显示正常

# ✅ 正确：断言具体可见的文字或控件
- aiAssert: 页面顶部标题或导航栏显示「设置」
- aiAssert: 设置页可见菜单项列表（如地图管理或设备信息等入口）
```

## 变量步骤上方保留原始字面量注释

使用 `{{key}}` 变量的步骤，上方必须用 `# -` 注释行保留原始字面量作为参照。

```yaml
flow:
  # - aiAssert: 地图可见「A区草坪 2000m²」「B区草坪 1500m²」「C区草坪 4000m²」等区域名称
  - aiAssert: 地图上可见「{{zones.a.mapLabel}}」或「{{zones.a.label}}」
  - aiAssert: 地图上可见「{{zones.b.mapLabel}}」或「{{zones.b.label}}」
  - aiAssert: 地图上可见「{{zones.c.mapLabel}}」或「{{zones.c.label}}」
```

`apply_device_env.py --apply` 会跳过 `#` 注释行，注释行始终保留原始参照，便于后续维护。

## 仅「查看/观察」

不要跳过，应写成：

```yaml
- ai: 查看状态栏当前时间
- aiAssert: 时间格式为 HH:MM，与联网时间一致
```

## 常用指令

| 指令 | 用途 |
|------|------|
| `ai: 点击…` | 点击可见控件 |
| `ai: 输入…` | 文本输入 |
| `ai: 等待直到页面显示"…"` | 智能等待 |
| `aiAssert: …` | **唯一推荐**断言形式 |

## B 档半自动

`flow` 只写到 Android 操作结束；不可 UI 判定的验收用注释：

```yaml
flow:
  - ai: 进入系统设置，将时间改为 14:30
# 人工验收：登录 Linux 执行 date，与屏显时间偏差 ≤1s
```

人工项清单：`midscene自动化输出/cases/*_B档半自动.csv` 的「人工验收项」列。

## 副作用分级（普渡机载）

| 级别 | 含义 | YAML 写法 |
|------|------|-----------|
| **无** | 只读 UI、返回 | 正常 `flow` |
| **写库** | 保存任务、命名写入首页列表 | `aiActContext` 建议固定任务名；说明 md 列清理名 |
| **启动作业** | 「开始作业」等真实执行 | task 末 `# 人工：作业结束后返回；台架执行` |
| **删数据** | 删除任务集、清空列表 | 放套件末尾；流水线默认跳过或单独跑 |

### aiActContext 模板（界面和任务设置）

```yaml
aiActContext: >
  已建图且定位成功。权限弹窗点允许；更新跳过。
  保存为任务会写入首页作业任务列表，建议命名「<套件名>自动化测试」便于清理。
  开始作业会真实启动作业，请在台架环境执行。
```

### 危险步骤注释模板

```yaml
      - aiAssert: 页面显示作业进行中或开始倒计时
# 人工：作业结束后返回；本 task 会真实启动作业
```

业务域套件与执行顺序见 [domain-ui-task-setting.md](./domain-ui-task-setting.md)。
