# 编辑已有任务 + 任务参数 — Midscene 自动化说明

**设计稿**：首页「编辑任务」→ 编辑任务页（保存/删除）→ 列表铅笔 → **A区草坪 任务参数设置**（割草/收集/收集+割草）

**终稿脚本**：`midscene自动化输出/scripts/编辑任务_自动化测试.yaml`（**18 条**）

## 与新建任务套件关系

| 套件 | 入口 | 页面标题 |
|------|------|----------|
| `新建任务_自动化测试.yaml` | 作业任务 → **+ 新建** | 新建任务 |
| `编辑任务_自动化测试.yaml` | 展开任务卡 → **编辑任务** | **编辑任务** |

建议顺序：`主界面_有地图有任务` → `新建任务`（可选）→ **本套件**。

## 前置条件

| 项 | 要求 |
|----|------|
| 数据 | 首页已有任务集（如「日常割草」，含 A区、B区 子任务） |
| 地图 | 已建图、定位成功 |
| 风险 | **最后 2 条会删除整单任务集**，测后需重建数据 |

## 执行

```bash
midscene run midscene自动化输出/scripts/编辑任务_自动化测试.yaml
```

## 注意

- 参数页区域名须与实机一致（`A区草坪` / `A区-前草坪`）。
- 按钮可能是「保存」或「保存任务」「确定」，脚本已兼容常见文案。
- **勿在删除后继续跑依赖「日常割草」的用例**；可重新执行 `新建任务_自动化测试.yaml` 造数。
