# 主界面「有地图-有任务」— Midscene 自动化用例说明

**设计稿状态**：有地图 · 有任务 · 任务列表默认展开 · 选中任务地图联动 · 开始作业

**终稿脚本**：`midscene自动化输出/scripts/主界面_有地图有任务_自动化测试.yaml`

## 前置条件

| 项 | 要求 |
|----|------|
| 地图 | 已建图，含 A/B/C/D 等作业区（名称可与稿略有差异，按屏上文案改 YAML） |
| 任务 | ≥2 个任务集，其中 **日常割草** 为默认任务（带星标） |
| 定位 | 定位成功，地图栏显示当前地图名 |
| 状态 | 空闲 |
| 设备 | 填写 `android.deviceId` |

## 自动化任务（13 条）

| # | 任务 | 用例 ID | 设计稿要点 |
|---|------|---------|------------|
| 1 | 作业任务面板展开/收起 | 12903557 | 默认展开；收起为「作业任务>」 |
| 2 | 任务名称与任务数 | 12903873 | 日常割草 / 2个任务 等 |
| 3 | 默认任务置顶 | 12903569 | 默认任务固定第一 |
| 4 | 展开详情+地图高亮 | 12903874 | 点击卡片展开；地图紫色高亮 |
| 5 | 选中/收起/切换 | 12903875 | 再点收起；切换任务联动高亮 |
| 6 | 编辑任务入口 | 12903879 | 展开后显示「编辑任务」 |
| 7 | 进入编辑页 | 12903835 | 编辑任务 → 编辑组合页 |
| 8 | 开始作业 | 12903883 | 底部绿色「开始作业」**会真实启动作业** |
| 9 | + 新建 | 12903548 | 标题栏「+ 新建」 |
| 10 | 地图区域标注 | 12903943 | A区-前草坪 等 |
| 11 | 定位按钮归中 | 12903947 | 挪图后点定位归中 |
| 12 | 定位丢失 Toast | 设计稿 | 切非定位地图 →「当前机器定位丢失」 |
| 13 | 地图栏名称 | 12904003 | 绿城·中央公园 |

## 执行

```bash
midscene run midscene自动化输出/scripts/主界面_有地图有任务_自动化测试.yaml
```

## 注意

- **任务 8** 会启动真实割草作业，建议在台架执行，跑完后手动停止或等待任务结束回到首页。
- **任务 12** 需存在至少 2 张地图；若仅一张地图，可跳过或改为模拟定位丢失环境。
- 任务集名称（日常割草/深度清理/快速修剪）须与实机一致，否则改 YAML 中可见文案。

## 与「有地图无任务」套件关系

| 套件 | 场景 |
|------|------|
| `主界面_有地图无任务_自动化测试.yaml` | 暂无作业任务、+ 新建任务 |
| `主界面_有地图有任务_自动化测试.yaml` | 作业任务列表、选中联动、开始作业 |

可合并进 `界面设置与操作_完整自动化测试.yaml` 作为独立 `groupName` 分批执行。
