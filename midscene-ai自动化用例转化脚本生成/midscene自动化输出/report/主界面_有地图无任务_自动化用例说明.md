# 主界面「有地图无任务」— Midscene 自动化用例说明

**截图状态**：空闲 · 已建图 · 绿城·中央公园 · A/B/C 草坪区 · 右侧「暂无作业任务」· 「+ 新建任务」

**终稿脚本**：`midscene自动化输出/scripts/主界面_有地图无任务_自动化测试.yaml`

## 前置条件（执行前确认）

| 项 | 要求 |
|----|------|
| 建图 | 至少一张地图，含 A/B/C 区标注（名称可与用例略有差异，脚本用可见文案匹配） |
| 定位 | 定位成功，地图栏显示当前地图名 |
| 任务 | 作业任务列表为空 |
| 状态 | 顶部显示「空闲」 |
| 设备 | 填写 YAML 中 `android.deviceId` |

## 自动化任务清单（9 条）

| # | 任务名 | 来源用例 ID | 覆盖点 |
|---|--------|-------------|--------|
| 1 | 地图栏展示当前定位地图名称 | 12904003 | 绿城·中央公园 / 地图栏 |
| 2 | 无任务时任务面板展开收起 | 12903556 | 暂无作业任务、收起/展开 |
| 3 | 有地图无任务引导文案 | 12903559* | 点击地图区域、快速创建文案（原 D 档，已改写 aiAssert） |
| 4 | 地图标注与底部快捷栏 | 12903943 | A/B/C 区、定位/设置/返航/回充 |
| 5 | 设置按钮跳转 | 12903886 | 设置页进入与返回 |
| 6 | 新建任务入口跳转 | 12903870 | + 新建任务 |
| 7 | 点击地图作业区快速任务 | 12903941 | 点击 A 区 |
| 8 | 新建任务页点击地图添加 | 12903350 | 新建页点 B 区 |
| 9 | 地图栏切换列表 | 12903736 | 点击地图栏弹窗 |

\*12903559 在筛选 CSV 中为 D 档（纯观察）；本套件已按 C 档改写为 `ai` + `aiAssert`，仅用于 UI 文案校验。

## 执行命令

```bash
midscene run midscene自动化输出/scripts/主界面_有地图无任务_自动化测试.yaml
```

## 已知注意

- **返航/回充**：未设置点位时仅验证 Toast/提示后可回到主界面，不断言机器人实际移动（对齐 12903888/12903896）。
- **区域名称**：若实机为「B区-东侧花园」等别名，请在 YAML 中将 `A区草坪`/`B区草坪` 改为实机可见文案。
- 精修后可将本套件与 `界面设置与操作_自动化测试.yaml` 合并或按模块拆分执行。
