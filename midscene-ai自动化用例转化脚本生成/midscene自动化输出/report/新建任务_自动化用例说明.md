# 新建任务流程 — Midscene 自动化用例说明

**设计稿覆盖**：点击新建 → 未添加/已添加 → **默认任务 / 定时作业** → 保存/删除 → **返回二次确认** → **删除二次确认 + Toast**

**终稿脚本**：`midscene自动化输出/scripts/新建任务_自动化测试.yaml`（**22 条** task）

## 前置条件

| 项 | 要求 |
|----|------|
| 地图 | 已建图，可见 A/B/C 等草坪区 |
| 入口 | 主界面「作业任务」→「+ 新建」 |
| 定位 | 定位成功 |
| 数据 | 保存/删除会改任务列表；建议测后清理「自动化测试任务」「待删除测试任务」 |

## 新增设计稿专项（本次补充）

### 返回二次确认（右图）

- 标题：**任务未保存**
- 文案：确定要返回吗 / 配置不会保存
- 按钮：取消（停留） / **返回**（回首页）

### 删除任务（左图）

- 底部红色 **删除** → 弹窗 **删除任务**
- 确认删除 → Toast **任务已删除** → **自动回首页**

### 默认任务 / 定时作业（右图）

- **定时作业 ON**：开关蓝色，默认任务未选中
- **设为默认任务**：显示 **已设为默认任务**，橙色星标；保存后首页列表置顶+星标

## 执行

```bash
midscene run midscene自动化输出/scripts/新建任务_自动化测试.yaml
```

## 注意

- 套件**按顺序执行**；13 保存后 14–21 会再次进入新建页，请勿中途改首页状态。
- 用例 20 **删除整单**会回首页；21 会再保存一条默认任务。
- 区域名、按钮文案请与实机一致（保存任务 / 删除 / 返回）。
