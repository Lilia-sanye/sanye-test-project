# 快速任务 — Midscene 自动化说明

**设计稿**：首页点地图进快速任务 → 任务列表/可添加区域 → **保存为任务**（键盘+居中弹窗）→ Toast 回首页 → **开始作业**

**终稿脚本**：`midscene自动化输出/scripts/快速任务_自动化测试.yaml`（**16 条**）

## 与新建/编辑任务规则一致

设计稿注明：添加、删除、拖拽、同区 5 次上限与 **新建任务**、**编辑任务** 相同。

| 套件 | 入口 |
|------|------|
| `新建任务_自动化测试.yaml` | + 新建 |
| `编辑任务_自动化测试.yaml` | 编辑任务 |
| `快速任务_自动化测试.yaml` | **点地图作业区** |

## 前置条件

- 已建图、定位成功、机器空闲
- 填写 `android.deviceId`
- 「开始作业」用例会真实启动作业（台架）

## 执行

```bash
midscene run midscene自动化输出/scripts/快速任务_自动化测试.yaml
```

## 注意

- 保存会新增任务集：`快速任务自动化测试`、`快速冒烟任务`，测后可删。
- 区域名请与实机一致（`A区草坪` / `A区-前草坪`）。
- 建议流水线：`主界面_有地图有任务` → **本套件**（或先 `新建任务` 造数）。
